## 4. 本会话（v1.2.0 发布后）解决的问题汇总

1. **模型文件集错误（核心，导致转写失败）**：large-v3 用 `vocabulary.json`，small/medium/base/tiny 用 `vocabulary.txt`（且无 `preprocessor_config.json`）。已改为按模型实际文件集下载 + 就绪判定「3 核心 + 词表」。
2. **下载进度恒 0 / 卡 0%**：状态同时带 `overall` 与 `frac`，前端 `overall ?? frac`；体积动态化。
3. **去下载式测速**：`_pick_sources` 改为 ModelScope 优先、hf-mirror 备份，直接开下、进度即刻可见。
4. **加载失败误切镜像**：仅在线下载模型时切 hf-mirror；本地加载失败直接抛错。
5. **无音轨视频**：`has_audio_stream` 检测，返回空字幕显示「未识别到语音内容」。
6. **英伟达机器转写卡死 + Failed to fetch**：多任务并发对同一模型原生推理导致原生崩溃（带崩服务进程）。已加**全局转写互斥锁 `_transcribe_lock`**。
7. **在线更新（v1.7.0）**：实现了从 GitHub `latest.json` 检查版本、下载 app 小包、SHA256 校验、退出后 PowerShell 辅助脚本覆盖 `app/` 并重启；设置页新增在线更新面板与镜像开关。
8. **转写/去词双核心修复（v1.8.0）**：统一预抽 16kHz 音轨 + VAD 放宽 + 空结果关 VAD 重试 + 词级时间戳；去词产物时长校验，剪辑未生效不再覆盖原文件。

## 5. 关键决策 / 约束

- **多显卡**：AMD/无 N 卡 = CPU int8（ctranslate2 Windows 无 ROCm），界面明确提示。
- **模型源**：ModelScope（国内直连）优先，hf-mirror 备份。**不要用下载式测速**（会先下 16MB 且无进度）。
- **就绪判定**：3 核心 + 至少一个词表文件，别再只查 model.bin。
- **打包**：模型排除、首启自动下载；`pack_full.ps1` 必须**纯 ASCII**（中文 Windows PowerShell 5.1 按 GBK 解析无 BOM 脚本会报错）；中文文件名（exe/启动.bat）用 `Get-ChildItem -Filter` 通配符找，不要写字面量。
- **pip 环境**：本机系统代理 `127.0.0.1:7890` 会劫持到清华源 TLS，pip 需 `--proxy ""` 或 `HTTP_PROXY="" HTTPS_PROXY="" NO_PROXY="*"`。打包内便携解释器与启动器都要设 `PYTHONNOUSERSITE=1`（隔离用户/全局 site-packages）。
- **CUDA 库首启自动下载（v1.4.0 起）**：`nvidia-cublas-cu12`/`nvidia-cudnn-cu12`/`nvidia-cuda-nvrtc-cu12` 不再封装进包（zip ≈150MB）。仅 NVIDIA 机器首启时自动下载（清华→阿里→腾讯 PyPI 镜像 + SHA256 校验 + 断点续传），解压到 `data/runtime/nvidia/` 并注册 DLL 路径；AMD/Intel 机器完全跳过。CUDA 下载失败自动降级 CPU，不影响使用。
- **模型清单**：`_fetch_ms_manifest()` 走 ModelScope 仓库文件 API（文件名/大小/SHA256）作下载与就绪核对清单，下载后落盘 `data/runtime/manifests/<model>.json`；PyPI simple 索引用连字符包名（nvidia-cublas-cu12），wheel 文件名为下划线。
- **打包 tar 坑**：Git Bash 里调 powershell 跑 pack_full.ps1 时 tar.exe 会命中 GNU tar（把 `D:` 当远程主机），需 PATH 前置 System32 或手工用 `/c/Windows/System32/tar.exe`。
- **在线更新（v1.8.0）**：只更新 `app/` 小包，不覆盖 `data/`、`logs/`、模型、视频、Python 运行时和 exe；下载必须 SHA256 校验；辅助脚本只杀项目目录内进程。app 小包放 `updates/` 随 git 推送发布，避免 GitHub Release 25MB 网页上传限制；完整包用于首次从旧版安装，本地 `build/updates/` 分发。
- **GitHub 发布**：仓库 `sreeny1/koubojiance`；`scripts/publish_update.ps1 -Publish` 需要本机 `git` 凭据和 `gh auth login`，不要把凭据交给 AI。
- **ffmpeg 7.1** 的 `select/aselect` 布尔组合（`not(between(...)+between(...))`）表现异常，去词用确定性的 `trim+concat`。

## 7. 开发环境与常用命令

```
# 本机 dev venv（Python 3.11，含全部依赖，AMD 机无 nvidia CUDA 库）
.venv\Scripts\python.exe app\main.py --no-browser      # 启动服务（127.0.0.1:87xx）

# 测试
.venv\Scripts\python.exe tests\test_selfcheck.py      # 模块自检
.venv\Scripts\python.exe tests\test_detector.py       # 检测器
.venv\Scripts\python.exe tests\test_split_segments.py # 字幕切分
.venv\Scripts\python.exe tests\test_cutter.py         # ffmpeg 去词
.venv\Scripts\python.exe tests\test_updater.py        # 在线更新（本地 HTTP，不联网）
.venv\Scripts\python.exe tests\e2e_test.py            # 全链路（需服务运行）

# 构建 / 打包
powershell -File scripts\build_launcher.ps1 -SkipFetch  # 编译 exe
powershell -File scripts\pack_full.ps1                  # 绿色完整包（约150MB，模型/CUDA 首启下载）

# 在线更新发布（-Publish 需要本机已保存 git 凭据；RepoHosted 走仓库 raw 直链，不依赖 GitHub Release API）
powershell -File scripts\publish_update.ps1 -Version 1.8.2 -Notes "更新说明" -RepoHosted -Publish
# 同时生成本地完整绿色包：
powershell -File scripts\publish_update.ps1 -Version 1.8.2 -Notes "更新说明" -RepoHosted -Full -Publish
```

## 8. 重要文件索引

- `app/core/model_downloader.py`：模型文件集/清单 API/就绪判定/下载（**重点**）
- `app/core/cuda_setup.py`：CUDA 运行库首启自动下载/校验/解压/就绪（**重点**）
- `app/main.py`：日志配置（setup_logging/启动横幅/请求中间件）与启动入口
- `logs/`：运行日志目录（`app.log` 服务端 / `launcher.log` 启动器；已排除出 git，排查问题先看这里）
- `app/core/transcriber.py`：转写引擎 + `_transcribe_lock`（**重点**）
- `app/server/tasks.py`：转写任务队列 + 模型预下载状态
- `app/server/cut_tasks.py` + `app/core/cutter.py`：去词
- `app/core/syscheck.py`：显卡/门槛
- `app/core/updater.py`：在线更新（检查/下载/SHA256/pending/覆盖 app/ 并重启）
- `app/web/static/app.js` + `style.css` + `index.html`：前端（主题/下载引导/悬浮提示/在线更新）
- `tools/Launcher.cs`：桌面外壳（原生拖放/深色/门槛/下载失败提示）
- `scripts/pack_full.ps1`：完整绿色包（**必须纯 ASCII**）
- `scripts/make_app_update.ps1`：生成 app 小包
- `scripts/publish_update.ps1`：同步版本号、写 latest.json；`-RepoHosted` 生成仓库直链 app 小包并随 git 推送；`-Full` 生成本地完整包；如本机已安装/登录 gh，也可用旧流程创建 GitHub Release（可选）
- `latest.json`：在线更新清单（main 分支根目录）；`updates/koubo-app-v<版本>.zip` 是随仓库发布的 app 小包，客户端从 raw 直链下载。
- `docs/开发文档.md`（架构）、`docs/开发日志.md`（过程史）
